# Dashspace Website

Static GitHub Pages-ready website for Dashspace LLC.

## Files
- `index.html` — company homepage
- `privacy.html` — website privacy notice
- `support.html` — support page
- `styles.css` — shared styling
- `assets/favicon.svg` — favicon

## Publish with GitHub Pages

1. Create a repository named exactly `dashspace-apps.github.io`.
2. Upload all files in this folder to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.
7. GitHub will publish the site at:
   `https://dashspace-apps.github.io`

## Before publishing
- Confirm `contact@dashspace.io` is an active email address.
- Replace placeholder app cards when real apps are ready.
- Review the privacy notice for your actual website/app practices before relying on it as legal documentation.
